# KAGGLE - BLACKJACK OUTCOME ANALYSIS (IDS2025 project)
Analyzing and predicting Blackjack results using data science 

TEAM:
Markkus Pokrovski

Kaggle dataset (61.77 MB): Public dataset containing 900,000 recorded Blackjack (Link: https://www.kaggle.com/datasets/mojocolors/900000-hands-of-blackjack-results )
hands with details about player and dealer cards, bets, and results.
Goal 1: Discover frequent patterns in winning and losing hands.
Goal 2: Predict the outcome of each hand using machine learning models (decision tree, k-NN, random forest)
Goal 3: Evaluate model performance
We analyze 900,000 Blackjack hands to identify key factors influencing outcomes. Through visualization and machine learning, we reveal data-driven insights into game dynamics and prediction accuracy.
